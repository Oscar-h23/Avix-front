# AVIX Front

Panel web de AVIX para consultar y administrar los registros operativos enviados a SIGO-BACK.

## Módulos iniciales

- Login por código de trabajador.
- Dashboard operativo.
- Historial con filtros por fecha, turno, franja horaria, acción, vía y placa.
- Turnos:
  - A: 06:00–14:00
  - B: 14:00–22:00
  - C: 22:00–06:00 del día siguiente.

El frontend consume el API AVI de SIGO-BACK.
